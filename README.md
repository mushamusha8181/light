# シンプルライト

Android用のシンプルなライトアプリです。小さなスマートフォンでも使いやすいよう、主要操作を48dp高に統一し、ホーム画面には日常的に使う操作だけを置いています。

## 主な機能
- LEDライト：弱 / 中 / 強 / OFF
- Android 13（API 33）以降で端末が対応している場合はLED強度を実際に変更
- 前回使った明るさを記憶
- 起動時に前回の明るさで自動点灯（設定でON/OFF）
- 自動消灯：なし / 1分 / 5分 / 10分 / 30分
- クイック設定タイルからON/OFF
- 画面全体を白くする「画面ライト」

## 権限
初回起動時に要求する実行時権限は `android.permission.CAMERA` のみです。フラッシュLED操作のためだけに使用し、撮影・録画・画像保存は行いません。

Quick Settings用の `android.permission.BIND_QUICK_SETTINGS_TILE` はユーザーへ要求する実行時権限ではなく、TileServiceへAndroidシステムがバインドするためのサービス宣言です。

位置情報、マイク、ストレージ、通知、インターネット権限は使用しません。

## 端末差
- LED強度制御は Android 13以降かつ対応ハードウェアのみ利用できます。
- 最大強度が2段階の端末では「弱」と「中」が同じ実強度になる場合があります。
- 強度制御非対応端末では「弱・中・強」は同じ物理的な明るさになります。画面上にもその旨を表示します。

## 自動消灯
通常時はアプリ内タイマーを使用し、端末がスリープした場合に備えて `AlarmManager.setAndAllowWhileIdle()` をバックアップとして使用します。古い予約が別のライト操作へ干渉しないよう、点灯セッションと現在プロセスの所有状態を確認してから消灯します。

Androidの仕様上、最後にライトを点灯したアプリのプロセスが終了すると、そのアプリが点けたライトもOFFになります。したがって、プロセス終了後の古い自動消灯予約はライト操作を行いません。

## クイック設定タイル
- Android 13以降：設定画面の「クイック設定に追加」から追加リクエスト
- Android 12L以前：Androidのクイック設定編集画面から手動追加
- Android 14以降：`PendingIntent` 版の `startActivityAndCollapse()` を使用
- カメラ権限を外した場合は、タイルに「権限が必要」と表示してアプリの権限導線を開きます

## 小型スマホUI
- 弱 / 中 / 強 / OFF / 画面ライト：48dp高
- 設定画面はスクロール対応
- 「クイック設定に追加」はダイアログ下部の3ボタン配置をやめ、本文内の48dpボタンに変更
- Android 15 / 16のedge-to-edge表示でシステムバーに操作部が隠れないようInsetsを処理

## ビルド環境
- Android Gradle Plugin: 8.10.1
- Gradle: 8.11.1
- Java: 17
- compileSdk / targetSdk: 36
- minSdk: 23
- versionCode: 4
- versionName: 3.1

`gradlew` / `gradlew.bat` はGradle 8.11.1を初回取得する自己ブートストラップ式です。取得したGradle ZIPは公式SHA-256で検証してから展開します。Android StudioではAndroid SDK 36を用意してください。
